# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows [Semantic Versioning](https://semver.org/).

---

## [1.0.0] - 2026-07-26

### Added

* First production-ready release of Scanitta.
* Live camera preview.
* Real-time barcode detection and decoding.
* Automatic barcode type identification.
* Latest scanned barcode display.
* Scan history with timestamps.
* Manual barcode entry.
* Empty barcode entry support.
* Text-to-speech for detected barcodes.
* CSV export for barcode lists.
* Responsive user interface.
* Project documentation.
* Production-ready repository structure.
